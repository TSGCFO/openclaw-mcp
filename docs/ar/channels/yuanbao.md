# [​](https://docs.openclaw.ai/ar/channels/yuanbao\#yuanbao)  Yuanbao

Yuanbao من Tencent هي منصة مساعد الذكاء الاصطناعي من Tencent. يربط Plugin قناة OpenClaw
روبوتات Yuanbao بـ OpenClaw عبر WebSocket حتى تتمكن من التفاعل مع المستخدمين
عبر الرسائل المباشرة ودردشات المجموعات.**الحالة:** جاهز للإنتاج للرسائل المباشرة مع الروبوت \+ دردشات المجموعات. WebSocket هو وضع الاتصال الوحيد المدعوم.

* * *

## [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D9%84%D8%A8%D8%AF%D8%A1-%D8%A7%D9%84%D8%B3%D8%B1%D9%8A%D8%B9)  البدء السريع

> **يتطلب OpenClaw 2026.4.10 أو أحدث.** شغّل `openclaw --version` للتحقق. حدّث باستخدام `openclaw update`.

1

[Navigate to header](https://docs.openclaw.ai/ar/channels/yuanbao#)

أضف قناة Yuanbao باستخدام بيانات اعتمادك

```
openclaw channels add --channel yuanbao --token "appKey:appSecret"
```

تستخدم قيمة `--token` تنسيق `appKey:appSecret` المفصول بنقطتين. يمكنك الحصول عليهما من تطبيق Yuanbao بإنشاء روبوت في إعدادات تطبيقك.

2

[Navigate to header](https://docs.openclaw.ai/ar/channels/yuanbao#)

بعد اكتمال الإعداد، أعد تشغيل Gateway لتطبيق التغييرات

```
openclaw gateway restart
```

## [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D9%84%D8%AA%D8%AD%D9%83%D9%85-%D9%81%D9%8A-%D8%A7%D9%84%D9%88%D8%B5%D9%88%D9%84)  التحكم في الوصول

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D9%84%D8%B1%D8%B3%D8%A7%D8%A6%D9%84-%D8%A7%D9%84%D9%85%D8%A8%D8%A7%D8%B4%D8%B1%D8%A9)  الرسائل المباشرة

اضبط `dmPolicy` للتحكم في من يمكنه مراسلة الروبوت مباشرة:

- `"pairing"` — يتلقى المستخدمون غير المعروفين رمز اقتران؛ وافق عليه عبر CLI
- `"allowlist"` — يمكن فقط للمستخدمين المدرجين في `allowFrom` الدردشة
- `"open"` — السماح لجميع المستخدمين (الافتراضي)
- `"disabled"` — تعطيل جميع الرسائل المباشرة

**الموافقة على طلب اقتران:**

```
openclaw pairing list yuanbao
openclaw pairing approve yuanbao <CODE>
```

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AF%D8%B1%D8%AF%D8%B4%D8%A7%D8%AA-%D8%A7%D9%84%D9%85%D8%AC%D9%85%D9%88%D8%B9%D8%A7%D8%AA)  دردشات المجموعات

**متطلب الإشارة** (`channels.yuanbao.requireMention`):

- `true` — تتطلب @mention (الافتراضي)
- `false` — الرد بدون @mention

يُعامل الرد على رسالة الروبوت في دردشة مجموعة كإشارة ضمنية.

## [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A3%D9%85%D8%AB%D9%84%D8%A9-%D8%A7%D9%84%D8%AA%D9%83%D9%88%D9%8A%D9%86)  أمثلة التكوين

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A5%D8%B9%D8%AF%D8%A7%D8%AF-%D8%A3%D8%B3%D8%A7%D8%B3%D9%8A-%D8%A8%D8%B3%D9%8A%D8%A7%D8%B3%D8%A9-%D8%B1%D8%B3%D8%A7%D8%A6%D9%84-%D9%85%D8%A8%D8%A7%D8%B4%D8%B1%D8%A9-%D9%85%D9%81%D8%AA%D9%88%D8%AD%D8%A9)  إعداد أساسي بسياسة رسائل مباشرة مفتوحة

```
{
  channels: {
    yuanbao: {
      appKey: "your_app_key",
      appSecret: "your_app_secret",
      dm: {
        policy: "open",
      },
    },
  },
}
```

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AA%D9%82%D9%8A%D9%8A%D8%AF-%D8%A7%D9%84%D8%B1%D8%B3%D8%A7%D8%A6%D9%84-%D8%A7%D9%84%D9%85%D8%A8%D8%A7%D8%B4%D8%B1%D8%A9-%D8%B9%D9%84%D9%89-%D9%85%D8%B3%D8%AA%D8%AE%D8%AF%D9%85%D9%8A%D9%86-%D9%85%D8%AD%D8%AF%D8%AF%D9%8A%D9%86)  تقييد الرسائل المباشرة على مستخدمين محددين

```
{
  channels: {
    yuanbao: {
      appKey: "your_app_key",
      appSecret: "your_app_secret",
      dm: {
        policy: "allowlist",
        allowFrom: ["user_id_1", "user_id_2"],
      },
    },
  },
}
```

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AA%D8%B9%D8%B7%D9%8A%D9%84-%D9%85%D8%AA%D8%B7%D9%84%D8%A8-@mention-%D9%81%D9%8A-%D8%A7%D9%84%D9%85%D8%AC%D9%85%D9%88%D8%B9%D8%A7%D8%AA)  تعطيل متطلب @mention في المجموعات

```
{
  channels: {
    yuanbao: {
      requireMention: false,
    },
  },
}
```

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AA%D8%AD%D8%B3%D9%8A%D9%86-%D8%AA%D8%B3%D9%84%D9%8A%D9%85-%D8%A7%D9%84%D8%B1%D8%B3%D8%A7%D8%A6%D9%84-%D8%A7%D9%84%D8%B5%D8%A7%D8%AF%D8%B1%D8%A9)  تحسين تسليم الرسائل الصادرة

```
{
  channels: {
    yuanbao: {
      // Send each chunk immediately without buffering
      outboundQueueStrategy: "immediate",
    },
  },
}
```

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%B6%D8%A8%D8%B7-%D8%A7%D8%B3%D8%AA%D8%B1%D8%A7%D8%AA%D9%8A%D8%AC%D9%8A%D8%A9-%D8%AF%D9%85%D8%AC-%D8%A7%D9%84%D9%86%D8%B5)  ضبط استراتيجية دمج النص

```
{
  channels: {
    yuanbao: {
      outboundQueueStrategy: "merge-text",
      minChars: 2800, // buffer until this many chars
      maxChars: 3000, // force split above this limit
      idleMs: 5000, // auto-flush after idle timeout (ms)
    },
  },
}
```

> يدعم Yuanbao قوائم أوامر الشرطة المائلة الأصلية. تتم مزامنة الأوامر إلى المنصة تلقائيًا عند بدء Gateway.

## [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D8%B3%D8%AA%D9%83%D8%B4%D8%A7%D9%81-%D8%A7%D9%84%D8%A3%D8%AE%D8%B7%D8%A7%D8%A1-%D9%88%D8%A5%D8%B5%D9%84%D8%A7%D8%AD%D9%87%D8%A7)  استكشاف الأخطاء وإصلاحها

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D9%84%D8%B1%D9%88%D8%A8%D9%88%D8%AA-%D9%84%D8%A7-%D9%8A%D8%B1%D8%AF-%D9%81%D9%8A-%D8%AF%D8%B1%D8%AF%D8%B4%D8%A7%D8%AA-%D8%A7%D9%84%D9%85%D8%AC%D9%85%D9%88%D8%B9%D8%A7%D8%AA)  الروبوت لا يرد في دردشات المجموعات

1. تأكد من إضافة الروبوت إلى المجموعة
2. تأكد من أنك تشير إلى الروبوت باستخدام @mention (مطلوب افتراضيًا)
3. تحقق من السجلات: `openclaw logs --follow`

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D9%84%D8%B1%D9%88%D8%A8%D9%88%D8%AA-%D9%84%D8%A7-%D9%8A%D8%AA%D9%84%D9%82%D9%89-%D8%A7%D9%84%D8%B1%D8%B3%D8%A7%D8%A6%D9%84)  الروبوت لا يتلقى الرسائل

1. تأكد من إنشاء الروبوت والموافقة عليه في تطبيق Yuanbao
2. تأكد من تكوين `appKey` و`appSecret` بشكل صحيح
3. تأكد من أن Gateway قيد التشغيل: `openclaw gateway status`
4. تحقق من السجلات: `openclaw logs --follow`

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D9%84%D8%B1%D9%88%D8%A8%D9%88%D8%AA-%D9%8A%D8%B1%D8%B3%D9%84-%D8%B1%D8%AF%D9%88%D8%AF%D9%8B%D8%A7-%D9%81%D8%A7%D8%B1%D8%BA%D8%A9-%D8%A3%D9%88-%D8%A7%D8%AD%D8%AA%D9%8A%D8%A7%D8%B7%D9%8A%D8%A9)  الروبوت يرسل ردودًا فارغة أو احتياطية

1. تحقق مما إذا كان نموذج الذكاء الاصطناعي يعيد محتوى صالحًا
2. الرد الاحتياطي الافتراضي هو: “暂时无法解答，你可以换个问题问问我哦”
3. خصصه عبر `channels.yuanbao.fallbackReply`

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AA%D8%B3%D8%B1%D9%91%D8%A8-app-secret)  تسرّب App Secret

1. أعد تعيين App Secret في YuanBao APP
2. حدّث القيمة في التكوين الخاص بك
3. أعد تشغيل Gateway: `openclaw gateway restart`

## [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D9%84%D8%AA%D9%83%D9%88%D9%8A%D9%86-%D8%A7%D9%84%D9%85%D8%AA%D9%82%D8%AF%D9%85)  التكوين المتقدم

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AD%D8%B3%D8%A7%D8%A8%D8%A7%D8%AA-%D9%85%D8%AA%D8%B9%D8%AF%D8%AF%D8%A9)  حسابات متعددة

```
{
  channels: {
    yuanbao: {
      defaultAccount: "main",
      accounts: {
        main: {
          appKey: "key_xxx",
          appSecret: "secret_xxx",
          name: "Primary bot",
        },
        backup: {
          appKey: "key_yyy",
          appSecret: "secret_yyy",
          name: "Backup bot",
          enabled: false,
        },
      },
    },
  },
}
```

يتحكم `defaultAccount` في الحساب المستخدم عندما لا تحدد واجهات API الصادرة `accountId`.

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AD%D8%AF%D9%88%D8%AF-%D8%A7%D9%84%D8%B1%D8%B3%D8%A7%D8%A6%D9%84)  حدود الرسائل

- `maxChars` — الحد الأقصى لعدد الأحرف في رسالة واحدة (الافتراضي: `3000` حرف)
- `mediaMaxMb` — حد رفع/تنزيل الوسائط (الافتراضي: `20` ميغابايت)
- `overflowPolicy` — السلوك عند تجاوز الرسالة للحد: `"split"` (الافتراضي) أو `"stop"`

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%A7%D9%84%D8%A8%D8%AB)  البث

يدعم Yuanbao إخراج البث على مستوى الكتل. عند تمكينه، يرسل الروبوت النص في أجزاء أثناء إنشائه.

```
{
  channels: {
    yuanbao: {
      disableBlockStreaming: false, // block streaming enabled (default)
    },
  },
}
```

اضبط `disableBlockStreaming: true` لإرسال الرد الكامل في رسالة واحدة.

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%B3%D9%8A%D8%A7%D9%82-%D8%B3%D8%AC%D9%84-%D8%AF%D8%B1%D8%AF%D8%B4%D8%A9-%D8%A7%D9%84%D9%85%D8%AC%D9%85%D9%88%D8%B9%D8%A9)  سياق سجل دردشة المجموعة

تحكم في عدد الرسائل التاريخية المضمّنة في سياق الذكاء الاصطناعي لدردشات المجموعات:

```
{
  channels: {
    yuanbao: {
      historyLimit: 100, // default: 100, set 0 to disable
    },
  },
}
```

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D9%88%D8%B6%D8%B9-%D8%A7%D9%84%D8%B1%D8%AF-%D8%B9%D9%84%D9%89)  وضع الرد على

تحكم في كيفية اقتباس الروبوت للرسائل عند الرد في دردشات المجموعات:

```
{
  channels: {
    yuanbao: {
      replyToMode: "first", // "off" | "first" | "all" (default: "first")
    },
  },
}
```

| القيمة | السلوك |
| --- | --- |
| `"off"` | لا يوجد رد مقتبس |
| `"first"` | اقتباس الرد الأول فقط لكل رسالة واردة (الافتراضي) |
| `"all"` | اقتباس كل رد |

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AD%D9%82%D9%86-%D8%AA%D9%84%D9%85%D9%8A%D8%AD-markdown)  حقن تلميح Markdown

بشكل افتراضي، يحقن الروبوت تعليمات في موجه النظام لمنع نموذج الذكاء الاصطناعي من تغليف الرد بالكامل في كتل كود markdown.

```
{
  channels: {
    yuanbao: {
      markdownHintEnabled: true, // default: true
    },
  },
}
```

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D9%88%D8%B6%D8%B9-%D8%A7%D9%84%D8%AA%D8%B5%D8%AD%D9%8A%D8%AD)  وضع التصحيح

فعّل إخراج السجلات غير المنقّح لمعرّفات روبوت محددة:

```
{
  channels: {
    yuanbao: {
      debugBotIds: ["bot_user_id_1", "bot_user_id_2"],
    },
  },
}
```

### [​](https://docs.openclaw.ai/ar/channels/yuanbao\#%D8%AA%D9%88%D8%AC%D9%8A%D9%87-%D9%88%D9%83%D9%84%D8%A7%D8%A1-%D9%85%D8%AA%D8%B9%D8%AF%D8%AF%D9%8A%D9%86)  توجيه وكلاء متعددين

استخدم `bindings` لتوجيه الرسائل المباشرة أو المجموعات في Yuanbao إلى وكلاء مختلفين.

```
{
  agents: {
    list: [\
      { id: "main" },\
      { id: "agent-a", workspace: "/home/user/agent-a" },\
      { id: "agent-b", workspace: "/home/user/agent-b" },\
    ],
  },
  bindings: [\
    {\
      agentId: "agent-a",\
      match: {\
        channel: "yuanbao",\
        peer: { kind: "direct", id: "user_xxx" },\
      },\
    },\
    {\
      agentId: "agent-b",\
      match: {\
        channel: "yuanbao",\
        peer: { kind: "group", id: "group_zzz" },\
      },\
    },\
  ],
}
```

حقول التوجيه:

- `match.channel`: `"yuanbao"`
- `match.peer.kind`: `"direct"` (رسالة مباشرة) أو `"group"` (دردشة مجموعة)
- `match.peer.id`: معرّف المستخدم أو رمز المجموعة
